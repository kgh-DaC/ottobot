연결이 안 될 때
  1. 로봇 전원을 켭니다. 블루투스 모듈 LED가 깜빡이면 연결을 기다리는 상태입니다.
  2. "연결"을 누르고 목록에서 로봇 이름(OTTO2, OTTO3 등)을 고릅니다. 로봇이 여러 대면 연결할 로봇만 켜 두세요. 목록에 없으면 "모든 기기 보기"를 켜 보세요.
  3. 휴대폰이나 다른 PC가 로봇에 연결돼 있으면 먼저 끊으세요. BLE 모듈은 한 번에 하나만 연결됩니다.
  4. Windows 설정의 블루투스 장치에 로봇을 "페어링"할 필요는 없습니다. 브라우저가 직접 연결합니다.
  5. 이 페이지는 http://localhost:8000처럼 로컬 서버로 열어야 합니다(파일을 더블클릭해 열면 블루투스가 막힙니다).
  6. 지원 브라우저: 데스크톱 Chrome/Edge, 안드로이드 Chrome. iPhone/iPad(Safari)는 지원하지 않습니다 — 데모 모드로 화면만 시험할 수 있습니다.
  7. USB 케이블: 목록에서 로봇의 COM 포트(예: COM10)를 고르세요. 연결하면 로봇이 재시작되어 약 3초 뒤 응답합니다. Arduino 시리얼 모니터·업로드 도구는 닫고 연결하세요. USB 전원만으로는 서보를 여러 개 움직일 때 전원이 부족할 수 있으니 배터리도 켜 두세요.
