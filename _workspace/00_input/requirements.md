# 요구사항 — Otto Fat 휴머노이드 펌웨어 + 웹 컨트롤러 (2026-11-24)

## 목표
ref/의 Otto DIY Fat 버전 로봇을 LED 매트릭스·터치·초음파·기울기(MPU6050)·블루투스로 구동하는 Arduino 펌웨어와, 브라우저에서 블루투스로 조종하는 웹페이지를 만든다.

## 하드웨어 (실물 진단 완료 — 상세는 otto-hardware 스킬 「2026-11-24 실물 진단 결과」)
- 보드: Arduino Nano(ATmega328P) + Otto Nano 쉴드, FQBN `arduino:avr:nano`, 업로드 포트 **COM10** (FTDI 호환칩: 유휴 시 이전 데이터를 반복 전달하는 드라이버 문제 있음)
- 서보: D2 왼다리(YL), D3 오른다리(YR), D4 왼발목(RL), D5 오른발목(RR), **D6 왼팔, D7 오른팔** — 모두 실물 확인
- 다리 트림: EEPROM 0~3에 **YL −10, YR 0, RL 0, RR 0** 저장 완료 → `Otto.init(..., true, ...)`로 로드. EEPROM 0~3은 다른 용도로 쓰지 않는다
- 초음파 HC-SR04: TRIG D8 / ECHO D9 — **현재 응답 없음(센서 불량 또는 전원 역결선 의심, 사용자 점검 대기).** 펌웨어는 부팅 시 감지해 없으면 장애물 반응을 끄고 계속 동작해야 함
- 블루투스: 장치명 **`otto2`, BLE UART 모듈**(HM-10/HC-08 계열 추정, MAC 98:DA:50:03:53:D9) ↔ Arduino SoftwareSerial D11(RX)/D12(TX) 9600bps. **웹은 Web Bluetooth로 연결** (클래식 HC-05 아님 — 실측 정정)
- 부저: D13 (수동)
- 터치: A0, 눌림 HIGH
- LED 매트릭스 MAX7219 8x8: CLK A1, CS A2, DIN A3, Orientation 1. `Otto.setLed(0,0)` = 정면 왼쪽 위, y=0 = 맨 위 행 (웹 편집기 좌표계와 동일)
- MPU6050: I2C 0x68 (A4/A5), WHO_AM_I 0x68. 바로 선 상태 pitch ≈ +6° → 0점 보정 필요. 앞으로 기울일 때 부호는 미확인(설정값으로)
- 사운드: A6 아날로그, 배경 51~54

## 기능
1. 이동·동작: Otto_APP move id 0~20 (전진/후진/회전/문워크/스윙 등), 속도·크기 조절, 연속 동작은 STOP까지 반복
2. 즉시 정지(STOP) — 어떤 상태에서도 최우선
3. 제스처 13종, 노래 19종, 부저 단음
4. LED 매트릭스: 입모양 0~30, 8x8 사용자 비트맵, 스크롤 텍스트, 상태 표정
5. 팔 서보 좌/우 각도 (Fat 버전 전용)
6. 다리 서보 직접 각도, 트림 설정·EEPROM 저장
7. 자동 반응 (켜고 끌 수 있음): 터치 정지, 초음파 장애물 후퇴(센서 있을 때만), 넘어짐 감지(서보 해제 + 회복), 소리 반응(선택)
8. 텔레메트리: 거리, 터치, pitch/roll, 소리, 상태 — 주기 설정
9. 이벤트 통지: 터치, 장애물, 넘어짐, 회복, 소리, 부팅
10. 웹: 한국어 UI, BLE 연결(기본) + USB Web Serial(디버그), 데모 모드(가상 로봇), 키보드 조작, 센서 시각화, 로그

## 제약
- RAM ≤ 75% (Nano 2KB)
- 웹은 외부 CDN·빌드 도구 없이 동작
- BLE 쓰기는 20바이트 단위 분할

## 가정
- BLE UART 서비스 UUID는 0xFFE0/0xFFE1을 기본 후보로 하고, 연결 시 실제 목록을 로그로 확인
- 팔 기본(내린) 각도는 90°, 하드웨어 시험 때 조정
