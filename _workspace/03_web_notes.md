# 웹 컨트롤러 구현 노트 (protocol version 1, 2026-11-24)

## 실행 방법
```
cd C:\Users\ghkim\Downloads\ottobot
python -m http.server 8000 -d web
```
Chrome 또는 Edge에서 `http://localhost:8000`을 연다. `file://`로 열면 ES 모듈과 블루투스가 막힌다(페이지가 안내 배너를 띄운다). 외부 CDN이나 빌드 도구는 쓰지 않는다.

- BLE(기본): 연결 방식 "블루투스 BLE" → 연결 → 목록에서 `otto2`. 목록에 없으면 "모든 기기 보기"를 켠다.
- USB(디버그): Arduino 시리얼 모니터를 닫는다 → "USB 시리얼" → COM10. 포트를 열면 Nano가 리셋되므로 1.8초 기다린 뒤 PING을 보낸다.
- 데모: "데모 로봇" → 연결. 하드웨어 없이 모든 화면을 시험할 수 있다. 데모 패널에서 터치, 넘어짐, 장애물, 소리, 전파 끊김, 센서 구성을 바꾸고 재부팅할 수 있다.

## 핵심 규칙 구현
- 모든 송신은 `encode()`를 거친다. `send(CMD.X, args)` 형태로 호출하고, 명령 문자열을 손으로 만드는 곳은 없다. 모든 수신은 `parseLine()`을 거친다. RAW는 로그에만 남긴다.
- 연결 직후 PING을 보낸다. INFO의 proto가 `PROTO_VERSION`과 다르면 배너로 펌웨어 재업로드를 안내한다. INFO.sensors와 INFO.auto로 AUTO 토글을 맞춘다. 센서가 없는 비트는 비활성화하고 이유를 표시한다. 초음파가 없으면 거리 칸은 "센서 없음", 있는데 0이면 "측정 실패"로 표시한다. 이어서 TELEM 200(선택 가능)을 보낸다. 탭이 숨겨지면 TELEM 0을 보낸다.
- 트림 화면은 TRIMS(YL −10)를 받기 전에는 잠겨 있다. 모르는 값으로 덮어쓰지 않기 위해서다.
- 이동: 방향 패드와 화살표/WASD는 누르는 동안만 움직인다. keydown 1회에 MOVE, keyup에 STOP을 보내고 OS 키 반복은 무시한다. 기타 동작 5~20은 누르면 STOP까지 반복한다. keepalive 간격은 `min(1000, max(500, ceil(period/3)))`이다. 속도와 크기를 바꾸면 새 MOVE로 교체하며 250ms로 쓰로틀한다. 창이 포커스를 잃거나 탭이 숨겨지면 누르고 있던 이동을 멈춘다.
- `d 77` 귀속(QA web_1 주요 1 수정): 현재 hold의 MOVE가 `a 77`을 받기 전에 온 `d 77`은 이전 동작의 몫으로 본다. STOP의 `a 83`보다 먼저 온 ACK는 STOP 뒤에 보낸 줄과 짝짓지 않는다(송신 순번으로 판정). 요청하지 않은 `d 77`은 경고로 띄우고 keepalive를 멈춘다. 경고에는 터치, 장애물, 넘어짐, 통신 감시 중 원인을 적는다. 자동 정지 뒤에 늦게 도착한 MOVE가 로봇을 다시 움직이면 STOP으로 취소한다.
- 이동 중 MOVE 0이면 `d 77`을 2번 기다린다(behavior.md 표 36행).
- 자동 정지 후 MOVE 잠금(통합 QA r1, behavior.md 4절 확정본):
  - (QA r2 반영) 장애물 후퇴를 사용자 STOP으로 끝내면 잠금이 없다. 웹은 STOP을 보내는 순간 후퇴용 추정 잠금을 지운다. 잠금 중에 홈(MOVE 0)을 누르면 이동 버튼처럼 잠금이 끝난 뒤 1회 보내고, 그래도 거부되면 "잠시 후 다시 누르세요"로 안내한다.
  - 펌웨어 규칙: 터치 정지, 장애물 후퇴(후퇴가 끝나거나 터치로 끝남), 통신 감시로 멈춘 뒤 홈을 마치고 IDLE이 된 시점부터 1000ms 동안 MOVE(id 0 포함)를 `e 3 77`로 거부한다. 사용자 STOP과 넘어짐에는 잠금이 없다.
  - 웹 동작:
    - TOUCH 이벤트를 받으면(AUTO 1, 이동 중 또는 후퇴 중) hold와 keepalive를 즉시 끊는다. OBSTACLE 이벤트(AUTO 2, 전진 계열 이동 중)와 요청하지 않은 `d 77`에서도 같다. 이때 누르고 있던 키와 버튼 상태도 버리므로 사용자가 다시 눌러야 움직인다.
    - 웹의 잠금 구간은 `d 77`을 받은 시각에서 1000ms에 200ms 여유를 더한 만큼이다. 장애물 후퇴는 텔레메트리에서 AVOID가 끝나는 것을 보거나 STOP의 `d 83`을 받은 시점에서 다시 잰다.
    - 잠금 중의 `e 3 77`은 토스트 없이 넘긴다. 잠금 중에 다시 누르면 잠금이 끝난 뒤 1회 보낸다. 그래도 거부되면 "잠시 후 다시 누르세요"로 안내한다.
    - 넘어짐으로 생긴 `d 77`은 hold만 풀고 잠금을 걸지 않는다. 사용자 STOP 응답 구간(`a 83`~`d 83`)의 `d 77`도 잠금을 걸지 않는다.
  - 데모: 루프 순서를 펌웨어와 같게 바꿨다(센서·안전 판정 → 입력 처리 → 감시 → 동작). 같은 잠금 규칙을 구현했다.
- 팔 슬라이더: STOP을 보낼 때, MOVE가 끝날 때(`d 77`: 자동 정지, 감시, home, 넘어짐 포함), RECOVER를 받을 때 90°로 되돌린다.
- 블로킹 명령(H K W G C M0)은 DONE을 받을 때까지 STOP 외의 버튼을 끈다. 이 상태에서 STOP을 누르면 재전송하지 않고, 남은 DONE 대기 시간에 1.5초를 더해 기다린다. 화면에는 "동작이 끝나면 바로 정지합니다"를 띄운다(QA web_1 주요 2 수정).
- FALLEN이면 배너를 띄우고 서보를 쓰는 버튼(이동, 제스처, 팔, 보정)을 끈다. AVOID일 때도 같다. 노래, 입모양, 매트릭스, 텍스트는 켜 둔다(behavior.md 허용표).
- 슬라이더 쓰로틀: 팔 200ms, 매트릭스 실시간 보내기 300ms, 트림 실시간 미리보기 400ms. 아직 보내지 않은 같은 종류의 명령은 큐에서 마지막 값으로 바꾼다(coalesce).
- 매트릭스 편집기 좌표 (x, y)는 `r[y]`의 `bit(7-x)`이다. 시험값: (0,0)을 켜면 r0 = 0x80. 프리셋에 실물 방향을 확인하는 그림 2개(왼쪽 위 한 점, 왼쪽 화살표)를 넣었다.
- 데모는 behavior.md 갱신분을 반영했다. MOVING·AVOID 중 넘어짐은 주기 끝 원시 샘플로 판정한다(60° 초과 2회 연속, 또는 한 번이라도 75° 초과). 터치로 정지하면 확인음만 내고 블로킹하지 않는다. PING은 얼굴을 바꾸지 않는다.

## 브라우저 제약
- Web Bluetooth: 데스크톱 Chrome/Edge와 안드로이드 Chrome에서만 된다. iOS Safari와 Firefox는 지원하지 않는다. 감지되면 BLE 항목을 끄고 데모를 기본으로 고른다.
- Web Serial: 데스크톱 Chrome/Edge에서만 된다.
- `http://localhost`나 https(보안 컨텍스트)에서만 동작한다. 휴대폰에서 PC의 http 서버(LAN IP)로 접속하면 보안 컨텍스트가 아니라서 BLE가 막힌다. 휴대폰으로 쓰려면 https로 호스팅하거나 휴대폰에서 직접 서버를 띄워야 한다.
- BLE 기기 선택 창은 사용자가 버튼을 눌러야만 열린다. 그래서 자동 재연결은 없다. 끊긴 뒤 "다시 연결"을 누르면 고른 기기에 선택 창 없이 다시 붙는다.

## 미구현·브라우저(실물) 확인 필요
- [실물 확인 필요] otto2의 실제 서비스와 특성 UUID. 연결 로그의 "서비스 …" 줄을 확인한다. 특성이 writeWithoutResponse를 지원하지 않으면 writeWithResponse로 대신 쓰는데, 이때 20B 분할 쓰기가 느려질 수 있다.
- [실물 확인 필요] BLE notify 조각 크기와 줄 조립(MATRIX 34B는 송신 2패킷, TELEMETRY는 최대 24B 수신).
- [실물 확인 필요] FTDI 반복 데이터의 실제 주기와 형태. 80ms 중복 창이 충분한지 본다. 반복이 줄 단위가 아니라 바이트 조각으로 섞여 들어오면 깨진 줄이 RAW로 로그에 남을 수 있다.
- [실물 확인 필요] pitch 부호(앞으로 기울 때 +인지). 화면 실루엣은 + 방향으로 시계 방향 회전한다. 부호가 반대면 펌웨어 config를 고친다(웹은 받은 값을 그대로 쓴다).
- [브라우저 확인 필요] 안드로이드 Chrome 터치 조작: 방향 패드를 누르고 있는 동안 스크롤되지 않는지(touch-action none 적용함), 매트릭스를 끌어서 그리기.
- [브라우저 확인 필요] 트림 저장 확인 대화상자(window.confirm). 헤드리스에서는 확인하지 않았다.
- ACK 타임아웃은 "1.5초 + period(MOVE 중)"이다. 실물 제스처나 노래가 30초를 넘으면 DONE 대기가 경고 후 풀린다. 실물의 가장 긴 동작 시간을 재서 확인한다.
- 데모의 입모양은 번호와 이름만 보여 준다. Otto 입모양 비트맵 미리보기는 구현하지 않았다.
- 데모는 소리를 내지 않는다(TONE, 터치 확인음은 상태 문자열로만 표시).
